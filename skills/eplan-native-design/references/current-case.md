# 历史案例与适用范围

复核这个已有案例时，按模型修订读取[已记录接口和故障经验](siemens-case-details.md)。其中历史 R2 的 TBD/旧额定值不得覆盖 A0/A1 的后续选型；其他工程不加载这些具体脚号。

本包来自一个西门子 PLC 控制变频器正反转的本机试验案例，包含独立安全回路、接口继电器、端子、中文标注及二维布局资料。它不是任意新工程的预先批准模板；用户实际采用接触器换相或其他 PLC 时应重新建模。

2026-10-24 的私有 A1 封存记录有 24 页、161 条原生连接、133 条逻辑路径、27 种工程内部部件与 90 条引用。这些数字仅描述那一修订，不能写成每次运行的预期值。没有本机数据时不声称复验这些统计。

原型写入计划使用固定 schema、编译哈希及原生对象基线。原生项目、计划、快照、厂家手册和交付包未公开进仓库；用户在私有配置中指向自己的可信工作目录。缺少计划时通用只读、文档检索和新设计意图校验仍可使用，历史写工具应报告缺失或范围不符。

历史参考使用 CPU1214C、V20、3SK1 等接口；确切物料与接线须按该工程模型、订货号、手册修订和当前设备核对，不从名称记忆推断脚号。工程内部部件记录不等于厂家原始宏，也不等于采购批准。实际供电、动力容量、停止行为、安全架构与现场验收不由旧快照代替。

案例图纸可用于已有授权范围的本机复核。公共 examples/control-intent.json 是独立编写的局部控制线网示例，含未知脚号/料号且不含完整安全或动力回路，不是这份私有工程的施工文件。
