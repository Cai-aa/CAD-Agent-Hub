# 电气设计、布局与交付工作流

## 需求与选型

区分输入已确认、设计假设与待确认值。三相 L1/L2/L3 是导体名称；线电压、相对 N 电压、频率、接地系统和电机铭牌须分别记录，不能从“220 V”推断成任意三相规格。电机正反转需区分接触器换相方案与变频器方向命令方案；普通继电器不直接承担未核实的三相电机功率。

部件记录需有厂家、订货号、修订/数据来源、线圈或供电电压、触点型式、端子定义及尺寸来源。BOM 的器件数量、接线端子位、桥接附件、安装附件和未选动力件分开核算。核实触点承载、保护配合、DC 负载抑制及安装散热间距。缺少选型依据时保留 TBD，不拿相似料号填空。

## PLC 盒子与端子

西门子紧凑 CPU 的电源、M/L+、分组公共端、DI/DO 和备用端子按确切 CPU 订货号与版本绘制，不能因同属 S7 系列复用脚号。模块化 PLC 需按各模块、槽位及独立公共端组织，不把相邻模块等同于内部相连。

每个通道同时保留设备标识、逻辑地址、符号变量、中文功能文本和实体连接点。`%I0.0` 与 `I0.0` 的别名不能产生重复通道；不同 PLC 控制器可以有各自地址空间。PNP/NPN 只描述输出/输入接口性质，不能单凭它猜每种模块公共端；公共端电位与分组仍以手册为准。AI/屏蔽/FE/PE、空置通道及未使用端子的处理分别核对。

## 原生元件及连接

发现实际符号库、功能定义、变体和连接点几何后再定位。连接点 API 索引不等于厂家端子印字；跨页同名中断点、星型源和排序关系属于网络语义，不能仅靠画面相交判断。

元件插入/移动后生成原生连接并读回对象类型、数据库、对象 ID、引脚索引、布置状态和电位。要求存在的路径与禁止存在的路径都核对。操作若移动接触器线圈或端子，要复核自动连接是否引入旁路和短接。对元件间留白、文字重叠、导线裁边、中文说明及跨页引用检查导出的实际页面。

正反转审查包含同时命令拒绝、硬件/软件互锁、停止优先、掉电与故障恢复防自启、复位不等于启动、换向停稳条件、故障/就绪反馈。电源隔离接触器不等同于已验证的安全停止；急停回路、EDM、停止类别及性能等级需由已确认的安全架构与风险评估支持。

## 二维布局与最终资料

电柜尺寸、导轨/线槽、走线空间、门板、端子可达性和散热间距使用真实数据。外形包络、2D 部件放置、开孔/加工尺寸及 3D 校核属于不同完成层次。未经尺寸来源和间距验证的矩形排布应注明为方案。

图册按封面/目录、逻辑、原理、PLC/I/O、端子/接线、BOM、布局等需求组织。导出的 PDF/表格/归档应来自同一修订；复核文件页数、文字、部件引用、数量及原生连接一致性。备份复制与哈希校验不等于已完成恢复演练。PLC 下载、运行测试、保护整定、现场验收没有做过就不写已完成。
