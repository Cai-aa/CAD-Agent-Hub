# 原生修改与恢复

本包 API 通过 GUI 线程队列执行；需要修改的对象保持在 LockingStep 范围内。当前工具不开放任意 Action、脚本、SQL、反射或任意工程路径写入。只读模式可读取已打开工程；试验写入仍受专用实例、固定工程、schema、计划哈希及对象前置条件约束。

执行前读取现状、保留备份与用户改动，并确认本次操作的后置条件。已有充分授权时直接进行支持范围内的可逆工作。工具不支持的能力要说明具体缺口；不能通过改名、删除身份或放宽哈希来绕过范围。

Python 管道请求有总截止时间，不自动重试写入。新 Add-in 能取消仍在排队的超时任务，返回 NATIVE_QUEUE_TIMEOUT_NOT_EXECUTED；已经执行的原生操作无法安全强停，结果未知时停止后续修改并先回读。老 DLL 尚未更新时不能宣称已有新的队列取消能力。结果文件存在、连接点对齐或几何线存在都不单独构成成功。

如果外接卷出现实际读写错误、断连或进程旧卷映射，应报告具体路径和错误；按用户对该卷的恢复要求操作。不自动格式化、修盘、删除锁文件或强行改变工程身份。磁盘状态提示与实际 I/O 失败分别记录。

重启只针对已识别的专用实例。先保存、备份并正常关闭工程，避免强制终止其他用户实例。重启后重新确认 build、工程路径和数据库身份；磁盘代码更新不代表 DLL 已换载。

同轮模型、采集器、路由清单和原生数据库身份绑定证据。迁移代码、改变模型或计划后旧快照应失效，不能改写旧报告哈希来让它通过。交付 PDF、BOM、布局、归档与验证记录使用同一修订，修改后只重做受影响检查。

工作站重绑还需哈希匹配的format/safety路由锚，不能只比较state中的当前路由。源码预检通过与原生实例/已加载DLL匹配分别验证；编译收据的MVID可用于拒绝同名旧程序集。一次超时或异常之后不自动重试写操作。
