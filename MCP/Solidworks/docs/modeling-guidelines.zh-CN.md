# SolidWorks 通用建模规范

本规范用于规划与验证，不能替代图纸。不要把某个样件的角度、尺寸或修补方法当作其他零件的模板。

## 中文工作树

默认使用“对象/用途＋操作＋必要参数”，如“底座轮廓草图”“安装孔定位基准面”“底座拉伸_10mm”。
数字、单位、R/C和标准代号可以保留。只有在没有用途信息时，才使用自动生成的“轮廓草图003”等后备名称。

图的`name`是内部ID，`display_name`是可选中文显示名。内部ID允许英文，图引用仍使用ID：

```json
{"name":"sk_base","display_name":"底座轮廓草图","kind":"sketch","plane":"Front Plane",
 "entities":[{"kind":"circle","radius_mm":10}]}
```

后续特征可以用`"sketch":"sk_base"`引用。编译器统一映射引用并返回`name_map`。
重复显示名、与系统基准面重名、`@`或控制字符会被拒绝。
独立编辑工具需要实际中文特征名/完整尺寸名；图ID不是通用的原生CAD持久句柄。
用户明确要求其他语言时，可以显式设置`metadata.tree_language`；默认中文不等于禁止英文内部ID。

## 拐角、圆角与倒角

先区分设计唇边/台阶与意外残料，不因“突出”就删除图纸中的设计形状。
明确交线、切点及倒角的轴向/径向/斜边长度和角度基准，非45°倒角尤其不能混用。

决定设计截面的圆角可以前置到草图；非关键的边缘修饰可以后置。
按几何依赖和选边稳定性决定圆角/倒角顺序，不规定所有圆角最后做，也不规定统一先圆角或先倒角。
前序特征改变后，重新核对被选择的边和数量；不要沿用旧索引。

对于有限斜切，起始面角度正确不代表整个切除体的侧边界正确。
需要计算切除方向和边界扫掠，检查近端、远端以及必要的中间截面是否始终贴合目标壁面。
可按条件使用方向引用、正确的终止面、安全扩大切除或对应截面放样；不能一律用放样。
放样需检查轮廓闭合方向、顶点对应和中间截面，避免扭转或鼓起。

## 参考面与坐标

区分模型坐标、草图坐标、图纸坐标和单位；进入API前统一换算。
三点基准面要检查相异性、尺度无关的共线条件和法向。
点序决定法向，不随意重排点来“修正方向”；显式确定拉伸/切除方向，再回读实际范围。
模型到草图的变换要检查有限性、正交性、尺度和手性；镜像要明确解释，不能静默翻转。
固定三点参考面不等于尺寸关联面。需关联更新时选用关联约束，否则保留可重生成的参数。

## 特征顺序与误差

先建立几何依赖，再安排主体、孔槽、关键修整和边缘处理。避免反复微移参考面“碰运气”完成布尔运算。
将图纸公差、读图估算、数值误差和未知量分开。修复时先隔离一个变量，不能为了通过检查任意放宽阈值。

## 分层验证

1. 重建状态、特征错误、预期特征存在性。
2. 实体数、范围、孔径/孔深/孔距、角度、体积；可计算的形状采用独立解析值。
3. 关键交界的局部视图/截面和边面连续性，检查短边、小面、薄楔、裂隙与过切。
4. 最终磁盘文件回读，以及中性文件的有容差几何对照；核对文件使用不同名称，避免导入标题混淆。
5. 材料、GD&T、粗糙度和热处理单列；仅写属性不能报告为制造要求已验证。

重建、包围盒和整体体积都可能漏掉局部缺陷。
`REVIEW_REQUIRED`是规划复核提示，`geometry_verified=false`明确表示离线工具尚未验证实体。

## 环境与文件

先确认实例PID和文档身份；目标不可用时不能静默改连其他实例。
保存失败区分几何、接口绑定、权限、磁盘和临时目录，不把环境错误都归因于模型。
有效TEMP/TMP只影响新启动进程，不能修复已运行实例的旧环境。

修改 Codex 配置时，MCP 启动项写入 `config.toml`，Skill 正文保留在各自的 `SKILL.md` 中。
先备份并比较解析后的配置，保留其他服务、模型和用户设置。
Windows 上不要将含 CRLF 的字符串交给会再次展开换行的文本写入接口；这会生成 CRCRLF，导致 Codex 拒绝整个配置。
本地部署使用 `scripts/config_toml_io.py`：规范化为 UTF-8/LF，直接解析待写入字节，检查并发修改，再以字节方式原子替换。
文件写完后还需用桌面版配套的 Codex 检查配置，再通过 stdio 握手与只读工具调用检查两个 MCP；仅 TOML 语法通过不能证明 MCP 已可用。

保留最终原生文件、中性文件、参数与来源、一套关键证据。
清理应限于当前授权范围，并记录清单；被占用或状态不明的文件不能强制处理。
一次清理授权不代表其他项目或以后每个任务都可自动删除。
