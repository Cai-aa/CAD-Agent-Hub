# SolidWorks MCP、Skill 与配置优化记录

## 来源与结构

来源为 Cai-aa/CAD-Agent-Hub，固定提交见模块 SOURCE_PROVENANCE.json，保留 Cai-aa 的 MIT 版权。
新增层包括：文档身份绑定、请求日志、覆盖保护、几何和重建验证、PDF证据与DrawingSpec、空间参考面、模型坐标草图、两截面切除放样、中文显示名、离线规划复核与配置字节写入。
不是只靠提示词实现的模型生成；MCP 负责有界执行和可检查结果，Skill 负责设计选择与证据要求。

## 主要故障与修复

| 表现 | 判定依据 | 修复与一般化规则 |
|---|---|---|
| 指尖出现薄楔残料 | 原图唇边为设计形状；斜切侧边界未全深度贴壁 | 对应两截面放样修复该案例；其它零件按边界选择方向、终止面或安全扩展，不能一律改放样 |
| 圆角与倒角相交失败 | 顺序、选边、切点和尺寸定义需要分别核对 | 设计轮廓圆角可前置，边缘修饰可后置，不规定统一顺序 |
| 空间参考面方向错误 | 点序、法向、单位、模型/草图坐标混淆 | 尺度无关共线性检查、变换正交/尺度检查、回读实际切除范围 |
| SaveAs 失败而几何正常 | 简单基体同样失败，旧进程继承失效临时目录 | 新进程使用有效 TEMP/TMP 并核对 PID；环境修正不改变已经运行的进程 |
| COM 属性被错误调用 | 返回 IDispatch 的属性也可能被 Python 判断为 callable | 区分方法与 COM 属性，不调用属性的默认成员 |
| Codex 整体配置加载失败 | 桌面日志：carriage return must be followed by newline | CRLF 被文本接口再次转换为 CRCRLF；采用 UTF-8/LF 字节原子写入，并解析最终字节和使用配套 Codex 检查 |
| 中文改名后引用失效 | 显示名和内部图 ID 混用 | 稳定 name + 中文 display_name，统一映射并返回 name_map；独立编辑使用实际特征/尺寸名 |

## 完整性守卫

现有文档写操作要求 document_token；请求 ID 绑定参数和目标，失败/超时不盲目重试。
保存拒绝隐式覆盖，重建、特征错误、实体数和正体积在保存前检查。
整体体积和包围盒可能漏掉薄楔、微小过切，需要局部截面和边面连续性证据。
固定三点面不冒充关联面；名义实体不证明 GD&T、热处理或制造要求已验证。
